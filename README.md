## Roadmap

The only execution plan for this repository is the OpenSpec change
`openspec/changes/harness-desktop/` (proposal, design, capability specs and
`tasks.md`). Desktop work is a client of the Harness Core contract v1; the
canonical copy of the plan lives in the Core repository.

- **Do not create a parallel Desktop roadmap.** Task progress is recorded in
  `openspec/changes/harness-desktop/NOTA_COPIA_DESKTOP.md` only.
- `openspec/changes/harness-desktop/tasks.md` must stay byte-identical to the
  canonical copy in Core; it is brought over as-is, never diverged.
- A task is checked off only with evidence from the current SHA: "looks right"
  and "local tests pass" are not evidence of a host or release obligation.
